# PersiaPad — ویرایشگر متن سبک با پشتیبانی کامل فارسی

یک Notepad حرفه‌ای و فوق‌سبک با پشتیبانی کامل از زبان فارسی،
رنگ‌بندی کد (Syntax Highlighting)، تم‌های متنوع، ذخیرهٔ خودکار لحظه‌ای.

---

## 🟢 می‌خواهی فقط یک EXE داشته باشی؟ (ساده‌ترین راه)

نسخهٔ فوری برنامه با **پایتون** نوشته شده و فوق‌العاده سبک است (بدون مرورگر، بدون نصب).
برای گرفتن یک فایل `PersiaPad.exe` فقط یکی از این دو کار را بکن:

### راه ۱ — ساخت exe با یک دابل‌کلیک (پیشنهادی)
1. روی فایل **`build.bat`** دابل‌کلیک کن.
2. صبر کن (۱ تا ۲ دقیقه). خودش PyInstaller را نصب می‌کند و exe می‌سازد.
3. فایل آماده اینجاست:  **`dist\PersiaPad.exe`**
   (یک کپی هم کنار همان پوشه ساخته می‌شود.)
4. همان `PersiaPad.exe` را هر جا خواستی کپی کن و دابل‌کلیک کن. ✅

> فقط کافی است **پایتون** روی ویندوز نصب باشد. اگر نبود، از
> <https://www.python.org/downloads/> نصب کن و موقع نصب تیکِ **Add to PATH** را بزن.
> این exe بعد از ساخته‌شدن، **بدون نیاز به پایتون** هم اجرا می‌شود.

### راه ۲ — اجرای مستقیم بدون ساخت exe
اگر پایتون نصب است، کافی است روی **`RUN.bat`** یا **`PersiaPad.pyw`** دابل‌کلیک کنی.

### راه ۳ — ساخت خودکار توسط GitHub (بدون هیچ کاری روی سیستم خودت)
این مخزن یک GitHub Action دارد (`.github/workflows/build-exe.yml`). با هر push روی ویندوزِ گیت‌هاب
فایل `PersiaPad.exe` ساخته می‌شود و در بخش **Actions → آخرین اجرا → Artifacts** قابل دانلود است.

> ⚠️ توجه: فایل `.exe` مخصوص ویندوز است و فقط روی ویندوز ساخته/اجرا می‌شود.
> این سندباکس لینوکسی است و نمی‌تواند مستقیم exe ویندوزی بسازد؛ به همین دلیل
> راهِ یک‌دابل‌کلیکیِ بالا آماده شده است.

## نسخهٔ بومی ویندوز (اختیاری)

یک نسخهٔ کامل **C# + WPF + AvalonEdit** هم در پوشهٔ `src/` هست (با installer در `installer/`).
این نسخه فقط روی ویندوز و با نصب .NET SDK کامپایل می‌شود.

## ⬇️ دانلود فایل نصبی آماده (بدون نصب هیچ ابزاری)

به‌جای ساخت دستی، گیت‌هاب به‌صورت خودکار روی سرور ویندوزِ خودش برنامه را build
کرده و فایل نصبی `PersiaPad-Setup.exe` را می‌سازد:

1. به تب **Actions** مخزن بروید: `https://github.com/vbnwq/notepad/actions`
2. آخرین اجرای **«Build PersiaPad Installer (.exe)»** را باز کنید.
3. در بخش **Artifacts** پایین صفحه، فایل **`PersiaPad-Setup`** را دانلود کنید.
4. آن را از حالت zip خارج و `PersiaPad-Setup.exe` را اجرا کنید → نصب با محیط گرافیکی.

> اگر یک tag مثل `v1.0.0` push کنید، فایل نصبی مستقیماً در صفحهٔ **Releases**
> هم منتشر می‌شود.

## 🛠️ ساخت فایل اجرایی (.exe) به‌صورت دستی روی ویندوز

> این پروژه فقط روی **ویندوز** کامپایل می‌شود (WPF). محیط لینوکس فقط برای نگه‌داری کد است.

### پیش‌نیاز
- **.NET 8 SDK** → https://dotnet.microsoft.com/download/dotnet/8.0
- (اختیاری برای ساخت نصب‌کننده) **Inno Setup 6** → https://jrsoftware.org/isdl.php

### روش ۱ — ساخت سریع exe مستقل (پیشنهادی برای سیستم‌های ضعیف/بدون دات‌نت)
```bat
build\publish.bat
```
خروجی: `build\publish\PersiaPad.exe` — همراه تمام وابستگی‌ها، روی هر ویندوزی بدون نصب دات‌نت اجرا می‌شود.

### روش ۲ — ساخت سبک (نیازمند .NET 8 Desktop Runtime روی مقصد، حجم کمتر)
```bat
build\publish-light.bat
```

### روش ۳ — ساخت همه‌چیز (exe + نصب‌کننده) با یک کلیک
```bat
build\build-all.bat
```
خروجی نصب‌کننده: `installer\Output\PersiaPad-Setup.exe`

### روش دستی (Visual Studio)
`src\PersiaPad.csproj` را در Visual Studio 2022 باز کنید و **Build** بزنید.

## 📦 نصب و تنظیم به‌عنوان برنامهٔ پیش‌فرض

1. `PersiaPad-Setup.exe` را اجرا و نصب کنید (نصب per-user، بدون ادمین).
2. در حین نصب، تیک «باز کردن فایل‌های .txt با PersiaPad» را بزنید.
3. برای پیش‌فرض‌کردن کامل: داخل برنامه از منوی **ابزار → تنظیم به عنوان برنامه پیش‌فرض**
   استفاده کنید؛ پنجرهٔ «Default apps» ویندوز باز می‌شود و PersiaPad را انتخاب کنید.

> برنامه در startup یا background اجرا **نمی‌شود** — وقتی ببندیدش کاملاً بسته می‌شود.

## 🧠 چطور ترتیب فارسی/انگلیسی درست می‌ماند؟

متن همیشه به‌صورت **منطقی (logical order)** ذخیره می‌شود و نمایش بصری را موتور
دوجهتهٔ یونیکد WPF (`TextFormatter`) انجام می‌دهد. به‌همین‌دلیل عبارتی مثل
«سلام chetory خوبی» همیشه با ترتیب درست کلمه‌به‌کلمه نمایش داده می‌شود؛ باگ
کلاسیک Notepad که ترتیب را خراب می‌کرد اینجا رخ نمی‌دهد. توگل «جهت راست‌به‌چپ»
در منوی **نما** فقط جهت پاراگراف را عوض می‌کند نه ترتیب کلمات داخل خط را.
